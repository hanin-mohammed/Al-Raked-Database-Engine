# Al Raked Car Wash Database Engine

Al Raked Car Wash Database Engine is an internal backend built with Google Sheets, Google Apps Script and Firebase. It manages service records, vehicle history, employee performance and automated reporting for the car wash.

I built this project to reduce repetitive administration and make business records easier to manage. The system is tailored to Al Raked’s daily workflow and is shared here as a project reference rather than a ready-to-use public application.
